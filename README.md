## 📖 Deskripsi Aplikasi
**Pre-Order** adalah aplikasi berbasis web modern yang dirancang khusus untuk mempermudah pengelolaan sistem pemesanan (*pre-order*) barang harian secara terpadu. Aplikasi ini memungkinkan pengguna untuk membuat toko, mengelola produk kustom, mengatur alur pesanan masuk, memantau pendapatan, serta berkolaborasi antaranggota tim toko secara *real-time*.

---

## 🛠️ Teknologi yang Digunakan
Proyek ini dibangun menggunakan tumpukan teknologi modern standar industri terkini:
* **Framework**: [Next.js](https://nextjs.org) (App Router, React Server Components & Client Components)
* **Bahasa Pemrograman**: TypeScript / JavaScript
* **Styling**: Tailwind CSS
* **Backend & Database**: [Supabase](https://supabase.com) (Authentication OAuth Google, PostgreSQL, Realtime Subscriptions, & Storage)
* **Deployment**: Vercel Platform
